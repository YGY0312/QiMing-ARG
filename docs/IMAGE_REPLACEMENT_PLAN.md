## 替换检查

1. 将审核后的成图放入 `src/assets/images/`，使用登记的正式文件名。
2. 在图片资源映射中切换到正式文件，将 `replacementStatus` 改为 `final`。
3. 在桌面与窄屏布局中确认裁切不遮挡周寻、书包和黄色挂件。
4. 根据正式图中人物位置只调整 0 到 1 的热点坐标，不重写照片查看组件。
5. 确认成图无文字水印、无真实学校标志，并完成剧情细节人工审核。

## 第二章视觉资料检查

第二章没有新增位图或 SVG 占位资源，因此无需新增待替换图片条目：

- 五月座位表由 HTML/CSS 的 18 个姓名卡组成，第 12 号座位及恢复交互是结构化数据，不依赖图片热点。
- 《窗外》附件由 DOC 式文本预览和结构化文件属性组成。
- 实验器材整理活动分组表由虚拟表格呈现。
- 顾言仅在普通文字新闻和调查草稿中出现，本阶段未使用人物照片。

如果后续将任一资料改为图片，必须先登记稳定资源 ID、占位与正式文件名、剧情用途、必须保留细节、建议画幅和相对坐标热点，再由页面资源解析器引用。
